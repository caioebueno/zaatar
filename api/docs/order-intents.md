# Order Intents API

Base URL (local): `http://localhost:4000`

---

## Upsert Order Intent

`POST /order-intents/upsert`

Auth: not required.

Creates or updates a customer's draft intent in a single call.  
Enforces: one customer can only have one active `OrderIntent`.

### Request Body (schema)

```ts
type UpsertOrderIntentBody = {
  id?: string | null; // existing OrderIntent id (edit mode)
  branchId?: string; // required when deliveryAddress is provided
  customerName?: string; // used to create customer if phone does not exist
  customerPhone?: string; // required when id is not provided
  active?: boolean; // default true
  language?: string | null;
  status?: "ACCEPTED" | "PREPARING" | "OUT_FOR_DELIVERY" | "DELIVERED";
  type?: "DELIVERY" | "TAKEAWAY" | null;
  paymentMethod?: "CARD" | "CASH" | "ZELLE";
  paymentProvider?: "STRIPE" | null;
  tipAmount?: number | null; // integer cents
  tags?: string[];
  progressiveDiscountSnapshot?: unknown;
  amount?: number | null; // integer cents
  deliveryAddress?: string | null; // full address text
  deliveryAddressId?: string | null; // explicit address id (skips search/geocoding)
  orderProducts?: Array<{
    id?: string; // optional, generated when missing
    productId: string;
    quantity: number; // integer > 0
    comments?: string | null;
    fullAmount?: number | null; // integer cents
    amount?: number | null; // integer cents
    modifierGroupItemIds?: string[];
  }>;
};
```

### Parameters

#### Headers

- none

#### Body fields

| Field | Type | Required | Rules |
|---|---|---|---|
| `branchId` | `string` | Conditional | Required when `deliveryAddress` is provided. Used as origin for delivery distance/fee calculation when creating address. |
| `customerName` | `string` | No | Optional name used when API must create a new customer because `customerPhone` was not found. Max length 120. |
| `customerPhone` | `string` | Conditional | Required when `id` is not provided. Digits only after normalization (`8-20` length). Must match an existing customer phone. |
| `id` | `string \| null` | No | If present, updates that specific intent by id. |
| `active` | `boolean` | No | On create defaults to `true`; on update, omitted means keep current value. If explicitly `true`, other active intents of same customer are deactivated. |
| `language` | `string \| null` | No | Max length 24. Empty string becomes `null`. |
| `status` | enum | No | `ACCEPTED \| PREPARING \| OUT_FOR_DELIVERY \| DELIVERED` |
| `type` | enum | No | `DELIVERY \| TAKEAWAY \| null` |
| `paymentMethod` | enum | No | `CARD \| CASH \| ZELLE` |
| `paymentProvider` | enum | No | `STRIPE \| null` |
| `tipAmount` | `number \| null` | No | Integer `>= 0` (cents). |
| `tags` | `string[]` | No | Unique values after normalization; each tag max length 60. |
| `progressiveDiscountSnapshot` | `unknown` | No | Stored as-is (JSON-compatible payload recommended). |
| `amount` | `number \| null` | No | Integer `>= 0` (cents). |
| `deliveryAddressId` | `string \| null` | No | If provided, API sets this address directly and skips `deliveryAddress` search/geocoding. |
| `deliveryAddress` | `string \| null` | No | Full address text. API searches existing customer delivery addresses by description (case-insensitive). If not found, API geocodes and creates a new delivery address. |
| `orderProducts` | `array` | No | If provided, replaces all existing intent line items. |

#### `orderProducts[]` fields

| Field | Type | Required | Rules |
|---|---|---|---|
| `id` | `string` | No | Generated by API when omitted. |
| `productId` | `string` | Yes | Must be a valid product id. |
| `quantity` | `number` | Yes | Integer `> 0`. |
| `comments` | `string \| null` | No | Max length 1000. Empty string becomes `null`. |
| `fullAmount` | `number \| null` | No | Integer `>= 0` (cents). |
| `amount` | `number \| null` | No | Integer `>= 0` (cents). |
| `modifierGroupItemIds` | `string[]` | No | Deduplicated; each entry must be a non-empty string id. |

### Behavior

- If `id` is provided:
  - updates that exact order intent by id.
- If `id` is omitted:
  - updates the current active order intent for that customer when one exists;
  - otherwise creates a new order intent.
- If `customerPhone` is provided but no customer exists:
  - API creates a new customer when `customerName` is provided.
  - without `customerName`, API returns `404 Customer not found`.
- If resulting intent is `active=true`:
  - all other active intents from the same customer are set to `active=false`.
- If `deliveryAddress` is a string:
  - API tries to find existing `DeliveryAddress` for that customer by description.
  - If none is found, API geocodes the text with Mapbox, calculates delivery fee, and creates a new `DeliveryAddress`.
- If `deliveryAddressId` is provided:
  - API validates the address id exists (and belongs to the same customer when customer is resolved in the request).
  - API skips `deliveryAddress` search/geocoding and uses this id directly.
- If `orderProducts` is provided:
  - existing line items are replaced with the supplied list.

```ts
type UpsertOrderIntentResponse = {
  id: string;
  customerId: string;
  active: boolean;
  createdAt: string;
  updatedAt: string;

  type: "DELIVERY" | "TAKEAWAY" | null;
```

### Error Responses

`400 Invalid payload`

```json
{ "error": "Invalid payload", "field": "customerPhone" }
```

or

```json
{
  "error": "Invalid payload",
  "field": "deliveryAddress",
  "reason": "DELIVERY_ADDRESS_NOT_FOUND_OR_UNSUPPORTED"
}
```

`404 Not found`

```json
{ "error": "Customer not found" }
```

or

```json
{ "error": "Order intent not found" }
```

or

```json
{ "error": "Branch not found" }
```
