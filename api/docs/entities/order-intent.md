# Entity: OrderIntent

## General Schema

```ts
type OrderIntent = {
  id: string;
  customerId: string;
  active: boolean;
  createdAt: string;
  updatedAt: string;
  language: string | null;
  status: "ACCEPTED" | "PREPARING" | "OUT_FOR_DELIVERY" | "DELIVERED";
  type: "DELIVERY" | "TAKEAWAY" | null;
  paymentMethod: "CARD" | "CASH" | "ZELLE";
  paymentProvider: "STRIPE" | null;
  tipAmount: number | null;
  tags: string[];
  progressiveDiscountSnapshot: unknown;
  amount: number | null;
  deliveryAddress: DeliveryAddress | null;
  deliveryAddressId: string | null;
  orderProducts: Array<{
    id: string;
    productId: string;
    quantity: number;
    comments: string | null;
    fullAmount: number | null;
    amount: number | null;
    modifierGroupItemIds: string[];
  }>;
};

type DeliveryAddress = {
  id: string;
  description: string;
  street: string;
  number: string;
  city: string;
  state: string;
  zipCode: string;
  lat: string;
  lng: string;
  deliveryFee: number;
};
```

## APIs

- `POST /order-intents/upsert`

## `POST /order-intents/upsert` Parameters

### Headers

- none

### Body

| Field | Type | Required | Rules |
|---|---|---|---|
| `branchId` | `string` | Conditional | Required when `deliveryAddress` is provided. Existing branch id used as origin for delivery distance/fee calculation. |
| `customerName` | `string` | No | Optional name used when API needs to create customer from `customerPhone`. Max 120 chars. |
| `customerPhone` | `string` | Conditional | Required when `id` is not provided. Digits normalized (`8-20`), must match an existing customer phone. |
| `id` | `string \| null` | No | If sent, updates that exact order intent by id. |
| `active` | `boolean` | No | On create defaults to `true`; on update, omitted keeps current value. When explicitly `true`, deactivates other active intents for customer. |
| `language` | `string \| null` | No | Max 24 chars. Empty string becomes `null`. |
| `status` | enum | No | `ACCEPTED \| PREPARING \| OUT_FOR_DELIVERY \| DELIVERED` |
| `type` | enum | No | `DELIVERY \| TAKEAWAY \| null` |
| `paymentMethod` | enum | No | `CARD \| CASH \| ZELLE` |
| `paymentProvider` | enum | No | `STRIPE \| null` |
| `tipAmount` | `number \| null` | No | Integer cents, `>= 0`. |
| `tags` | `string[]` | No | Deduplicated; each tag max 60 chars. |
| `progressiveDiscountSnapshot` | `unknown` | No | Stored as JSON snapshot. |
| `amount` | `number \| null` | No | Integer cents, `>= 0`. |
| `deliveryAddressId` | `string \| null` | No | Explicit address id. When provided, API uses this id and skips `deliveryAddress` text search/geocoding. |
| `deliveryAddress` | `string \| null` | No | Full address text. API finds existing customer address by description or creates one from Mapbox geocoding. |
| `orderProducts` | `array` | No | Replaces existing intent line items when provided. |

### `orderProducts[]`

| Field | Type | Required | Rules |
|---|---|---|---|
| `id` | `string` | No | Generated by API when omitted. |
| `productId` | `string` | Yes | Product id. |
| `quantity` | `number` | Yes | Integer `> 0`. |
| `comments` | `string \| null` | No | Max 1000 chars. |
| `fullAmount` | `number \| null` | No | Integer cents, `>= 0`. |
| `amount` | `number \| null` | No | Integer cents, `>= 0`. |
| `modifierGroupItemIds` | `string[]` | No | Non-empty ids, deduplicated. |

## Rules

- A customer can have only one active order intent.
- Upsert will update existing active intent or create a new one when needed.
- When `orderProducts` is included, line items are replaced.
